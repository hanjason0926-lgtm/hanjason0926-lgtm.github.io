# 灰燼誓約

## 專案大綱

《灰燼誓約》是以 Three.js 製作的 3D 暗黑奇幻動作 RPG。玩家將探索被森林吞噬的哥德式聖殿，擊敗四名守衛，最終挑戰巨型鹿角騎士。

遊戲採用單一 `index.html` 靜態架構，將畫面、樣式、Three.js 渲染、角色操控、戰鬥系統、特效與 HUD 整合於同一檔案，可直接透過 GitHub Pages 執行。
