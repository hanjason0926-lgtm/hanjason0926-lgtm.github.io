# 灰燼誓約 — 直接開啟 HTML 的離線版

雙擊同資料夾的 **index.html**，使用 Chrome 或 Edge 開啟，按「踏入聖殿」即可遊玩。

不需要 Node.js、不需要安裝套件、不需要啟動服務，也不需要網路連線。只要保留這一個 HTML 檔即可複製到其他電腦遊玩。瀏覽器需支援 WebGL 2 並啟用硬體加速。

## 操作

| 操作 | 按鍵 |
| --- | --- |
| 移動 | W A S D 或方向鍵 |
| 面向目標 | 滑鼠指向 |
| 斬擊／連段 | 左鍵或 J，按住可連擊 |
| 翻滾 | 空白鍵 |
| 正面格擋 | 按住右鍵或 K |
| 雷霆魔法 | Q |
| 回血 | E |
| 營火補給 | 靠近營火按 F |
| 角色裝備 | I |
| 暫停／繼續 | Esc |

畫面右上角可調整音效、全螢幕與畫質。先擊敗四名守衛，再挑戰鹿角王。重新整理 HTML 會回到標題畫面，進度不會存檔。
