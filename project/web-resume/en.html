01AI Knowledge Base

業務部門 AI 知識庫

內部專案 / 規劃與開發

業務部門面對大量分散的文件、報告與資料，查找耗時、也難以重複利用。我打造一套以 AI Agent 為核心的知識庫，讓團隊能以自然語言查詢，快速取得摘要、來源與相關內容，把分散的知識整合成可即時檢索、可引用的資產。

系統會針對上傳的文件自動生成摘要與分類，並保留來源可追溯，讓業務在面對客戶問題時能即時找到依據，而不必再翻遍雲端硬碟與歷史檔案。

02CRM · CDP · DMP Data Architecture

客戶數據平台・數據架構

企業客戶外部專案 / 底層數據架構與數據呈現

外部專案最常見的痛點，是系統要上線了，資料卻還停留在分散、欄位定義不一致、報表只能人工整理的狀態。我先後參與 CRM、CDP、DMP 三類專案，負責制定數據架構，從管理報表與觀察需求回推資料模型，規劃欄位對應、篩選邏輯、指標定義與日排程資料流程。

CRM：將原本依賴多份 Google 表單、資訊分散的作業，轉為可管理的資料架構。CDP：規劃跨系統客戶資料整合與特徵欄位設計，支援後續分群與預測模型。DMP：制定 Data Lake、Data Warehouse 與 Data Mart 分層，依需求設計 Star / Snowflake Schema，並支援 Power BI 儀表板所需的資料模型。

在雲端資料整合上，運用 Google Cloud Data Fusion 建立跨來源的資料融合（data fusion）管線，並以 BigQuery 作為雲端資料倉儲，支撐大規模資料的儲存、查詢與分析。

SQLData ModelingStar / Snowflake SchemaData LakeETLCloud Data FusionBigQueryGCPPower BI
03AEO Content Automation

AEO 部落格自動產生系統

內部專案 / 從零設計與建置

在缺乏前後端資源的情況下，公司希望經營 AI 搜尋曝光與品牌內容，卻難以穩定產出可被搜尋與引用的頁面。我以 agent skills 建立一套 AEO 內容自動化流程：從網路蒐集高關注議題、轉寫文章，到以 Python 自動轉為 HTML 與 JSON-LD，並串接既有 FTP 成站機制完成自動上架。

最終讓公司在低開發資源下，仍能持續產出可被 AI 搜尋、理解與引用的內容頁面，實際提升品牌內容的可見度與擴充效率。

04Backend · LINE Bot Platform

LINE Bot 後台系統

內部專案 / 從零獨立設計與開發

公司當時完全沒有 LINE Bot 系統，客服與用戶互動全靠人工一對一回覆，無法擴張也難以追蹤。我從無到有獨立設計並開發整套系統：資料模型、訊息回覆規則引擎、Django + NGINX 部署架構，以及串接訂單與會員資料的個人化回應機制。管理後台讓客服與行銷可自行設定關鍵字觸發規則與回覆內容，不需每次找工程師改程式；並另建供應商評價雷達圖查詢站台，支援採購部門的評比決策。

語意分析｜從 LINE 對話中找規律：客服累積大量對話紀錄，卻充滿錯字與口語縮寫，難以直接分析。我建立一套文本清洗與語意分析流程，以字音轉換修正常見錯字、結巴分詞加詞性標註過濾停用詞，最後輸出週期性詞頻統計與主題分群報告，整個流程容器化後可定期自動執行。客服團隊第一次拿到「用戶最常問的 Top 20 問題」清單，能有依據地調整常見問題區與 Bot 預設回應。

05Government Data Research

政府數據研究專案

政府委託研究標案 / 主承辦・獨立主導

獨立主導一項 300 萬元政府委託研究標案，身為主承辦負責全案數據分析與報告撰寫。以 SQL Server 建立批次匯入與標準化儲存流程，搭配 Python 自動篩除極端異常值，並運用多項式與指數迴歸模型推估無法直接量測的關鍵參數，將複雜問題轉化為可供政策引用的定量結論。

研究成果正式典藏於國家圖書館，為相關管理制度提供具方法論基礎的改革依據。
